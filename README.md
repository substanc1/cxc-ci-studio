# cxc-ci-studio

Открытый репозиторий сборок CubeX Builder Studio (CubeXCraft).

- Workflow `build` собирает приложение под Windows, macOS (universal), Linux x64 и Linux ARM64.
- Исходники лежат в `payload.bin` в зашифрованном виде (AES-256, ключ — секрет репозитория). Открытого кода здесь нет.
- Результат каждой системы шифруется тем же ключом в `result.bin` и выгружается как артефакт `result-<система>` на 1 день.
- Подпись обновлений и ключ шифрования хранятся только в секретах GitHub. Здесь их нет и быть не должно.

Запуск: вручную (`workflow_dispatch`) или тегом `v*`.

## Сообщить о проблеме

Откройте Issue в этом репозитории. В Issue не вставляйте секреты, ключи, пароли, токены, расшифрованные файлы и логи сборки целиком: логи могут содержать пути и переменные. Опишите шаги, ОС и текст ошибки короткой выдержкой.

Уязвимости — не через публичные Issues, см. [SECURITY.md](SECURITY.md).
